# Kylo Ren / Admiral Trench — Twin Suns
**Format:** Twin Suns | **Aspects:** Vigilance, Cunning, Villainy | **Synergy:** TBD | **Avg Cost:** ~3.4

## Strategy
Sith attrition + Separatist space control. Early turns: chip with cheap Sentinels and droids, use Kylo's action to cycle upgrades (discard bad ones, draw). Mid-game (5–7): stabilize space with Munificent / Invincible / Providence while Sith events clear problem units. Trench epic-deploys for free on turn 6 off his 3-cost Action. Late game: Kylo deploys and pulls upgrades out of discard (Snapshot Reflexes, Kylo's TIE Silencer, Vader's Lightsaber) for a one-turn kill; Malevolence or Invisible Hand closes the base.

## ⚠️ Caveats

1. **Card list is a rough draft.** The 80-card list above was synthesized from a research agent and includes a few cards where set codes or exact versions should be verified on swudb.com before buying. Treat this as a starting draft, not a locked list.

2. **Trench aspect correction.** Initial guess was Vig/Vil — research confirmed **Cunning**/Villainy. This actually helps — 3-aspect pool (Vig/Cun/Vil) is stronger than 2, and unlocks the whole TWI Separatist toolkit.

3. **Not enough Sentinels early.** Kylo WNDY's survival plan relies on living to turn 7 for the deploy blowout. The current list is light on 1–2 cost Sentinels. Add a few (e.g., cut utility events) if early defense feels soft in playtesting.

4. **Upgrade count is heavy.** The Kylo recursion package + Sith upgrades adds up. Make sure the ground body count can actually wear them — this deck needs ~12 ground units minimum to not dead-draw upgrades.

5. **This list competes for cards with the Thrawn/Annihilator deck** — Moff Gideon, Rampart, Invincible, Targeting Computer, Boba spotlight pieces all overlap. Can't sleeve both simultaneously without a second copy pool.
